# Cymb

## Features

Cymb is a tool for C development. It contains:
- A compiler
- An assembler
- A linker
- A standard C library implementation

It can also be linked into a program to use its features, such as generating ASTs.

A basic example to compile a file from the command line: `cymb -c main.c -o main.o`.
For further options, use `cymb --help`.

## Requirements

Cymb only supports Linux and Windows on x86-64 and little-endian AArch64.
